# Asset research — batch 5: Canada, Mexico, Brazil, Argentina, Nigeria

Research date 2026-11-07. **Research only: nothing here has been downloaded.** Source: Sketchfab public search API (downloadable, CC BY, ≤120k faces; 40 queries, 386 unique results, then keyword/face-count filter). Title, author handle and face counts are the API's own values. Link form: `https://sketchfab.com/3d-models/<id>`. All candidates are **CC BY 4.0**.

**Excluded on purpose:** Oxxo (a real convenience-store brand), YPF canopies (a real fuel brand), Land Rover / Dacia / Suzuki items (car brands), characters, animals, statues, interiors, masks/heads, models over about 60k faces unless cut up.
